# Tandas

App web instalable para planificar comidas por tandas, controlar la despensa y el gasto por ración.

- Funciona sin conexión una vez instalada.
- Tus datos (despensa, tickets, clave de API) se guardan solo en tu móvil.
- La lectura de tickets y el asistente usan la API de Anthropic con tu propia clave (Ajustes).

Archivos: `index.html`, `app.css`, `app.js`, `data.js` (catálogo y recetas), `sw.js` (modo sin conexión), `manifest.webmanifest` e `icons/`.
